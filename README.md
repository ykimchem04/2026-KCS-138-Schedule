# KCS 138 일정

대한화학회 제138회 학술발표회(2026년 10월 28–30일, 수원컨벤션센터)의 발표 일정을
폰에서 보기 위한 사이트. 발표 1,091건 — 그중 776건이 포스터다.

```bash
py scripts/fetch_abs.py     # kchem.org -> data/abstracts.json
py scripts/build_data.py    # -> docs/data.json
py scripts/build_site.py    # -> docs/index.html
```

## 화면이 둘이다

폰과 PC는 같은 화면을 늘리거나 줄인 것이 아니라 서로 다른 레이아웃을 받는다.
경계는 1024px이고, 넘나들 때 간격만 바뀌는 것이 아니라 구조가 바뀌므로 다시 그린다.

- **PC는 학회 프로그램 표를 쓴다.** 회장이 가로, 시간이 세로이고, 세션은 자기가
  실제로 차지하는 행만큼 `rowspan`으로 뻗는다. 사흘 중 가장 복잡한 날이 회장 14개라
  표는 가로로 넘긴다. 종이 프로그램을 보던 방식 그대로다.
- **폰은 목록과 하단 탭이다.** 회장 14개짜리 표는 폰에서 쓸 수 없다. 시작 시각으로
  묶은 한 줄짜리 목록을 주고, 탭은 엄지가 닿는 아래에 둔다. 검색 결과와 포스터
  목록도 PC에서는 표, 폰에서는 행이다.
- **터치 영역은 44px이다.** 별표 글리프는 18px이지만 탭 영역은 44px로 키우고 음수
  마진으로 행 높이를 되돌린다. 계획 전체가 이 버튼 하나에 걸려 있다.
- **첫 화면이 시계를 안다.** 학회장에서 폰을 꺼내는 이유는 사흘치 표가 아니라 "지금
  어디로 가지"다. 학회 주간이 아니면 첫날 오전으로 고정한다.
- **포스터가 동급이다.** 1,091건 중 776건(71%)이다. 곁다리일 수 없다.
- **검색은 한국어로도 찾힌다.** API가 영문 일색이라 분과명을 양쪽 언어로 색인한다.
  `고분자`가 0건이던 것이 67건이 된다.

목록을 다시 그리는 일은 아낀다. 별표를 누르면 그 버튼과 행만 바꾸고, 검색창에 타자를
치면 결과 영역만 갈아끼운다. 화면을 통째로 다시 그리면 엄지로 쓸어 내린 스크롤이
날아가고, 입력창에 포커스가 돌아오면서 키보드가 다시 올라온다.

경계를 넘는 순간을 잡는 데는 `resize`를 쓴다. `matchMedia`의 `change`가 더 싼
신호지만 1440 → 375 축소에서 한 번도 오지 않아 폰에 회장 표가 그대로 남았다. 둘 다
걸어 두되 실제로 믿는 쪽은 `resize`이고, 경계가 진짜 뒤집혔을 때만 다시 그린다.

## 생김새는 대한화학회를 따른다

색과 서체와 표의 모양은 학회 사이트에서 가져왔다. Noto Sans KR 한 벌, 흰 바탕에
남색 `#003F87`, 활성 탭 `#2367B2`, 표머리 틴트 `#EBF3F9`, 테두리 `#DEE2E6`,
모서리는 탭 10px·표 5px. 떠 있는 둥근 카드나 장식용 강조색은 쓰지 않는다 — 학회
사이트가 그렇지 않다.

## 연락처는 가져오지 않는다

API는 레코드마다 발표자의 **이메일과 휴대폰 번호**를 함께 준다. 1,091명분이다. 발표
초록을 내려고 적은 정보지 명단에 실리라고 낸 것이 아니고, 정적 사이트에 올리면
크롤러가 가져간다.

그래서 `fetch_abs.py`는 **허용 목록**으로 읽는다. 쓸 필드를 이름으로 지정하고 나머지는
버린다. 뺄 것을 지정하는 방식이었다면 API에 필드가 하나 늘었을 때 조용히 흘러나왔을
것이고, 그 실패의 대가가 연구자 1,000명의 전화번호다. 걸러낸 값은 중간 파일로도
디스크에 쓰지 않는다.

초록 본문에 저자가 직접 적어 넣은 주소(`*Corresponding author: ...`)도 지운다. 그건
인쇄되라고 쓴 것이지만 프로그램북과 크롤링되는 웹페이지는 다르고, 본문만 예외로 두면
아래 검사를 못 믿게 된다.

쓰기 직전에 두 가지를 검사하고, 걸리면 **쓰지 않고 중단한다**: 연락처처럼 보이는
필드명(`email`, `mobile`, `cv…`, `authority` 등)이 남아 있는지, 그리고 직렬화한 결과
전체에 이메일 모양 문자열이 있는지.

## 원본 데이터에서 고친 것

`getAbsListAjax`는 초록 한 건당 한 행을 주고 그 위의 구조는 주지 않는다.

- **`day`는 날짜가 아니라 인덱스다.** 2/3/4가 사흘에 대응한다. 숫자만으로는 뜻이
  없어서 각 행이 함께 주는 한글 요일과 대조한다. 어긋나면 중단한다.
- **포스터에는 시각이 없다.** 776건은 시각 자리에 `발표III`–`발표VI`라는 세션 이름이
  들어 있다. 실제 시각은 프로그램 페이지에만 있어서 `build_data.py`에 적어 뒀고,
  각 세션에 어느 분과가 들어가는지도 함께 적어 대조한다. **Poster 4는 14:30–16:30**로
  다른 셋과 다르다 — 패턴으로 짐작했으면 틀렸을 자리다.
- **다섯 행은 시각 표기가 깨져 있다.** `09.00-09:40`(콜론이 마침표), `10:05~10:25`
  (물결표) 넷. 버리지 않고 정규화한다.
- **`LIFE.O-6`은 `day 0`(월요일)이다.** 사흘 다 수·목·금인 학회에서 불가능하다. 같은
  세션·같은 홀의 나머지 다섯 건이 모두 3일차이고 이 발표의 시작 시각이 직전 발표의
  종료 시각과 정확히 맞물려서, 형제 행들이 만장일치일 때만 그 날짜를 빌려 온다.
  고쳤다는 사실은 빌드 로그에 남긴다.

**세션은 유도한다.** 같은 트랙·같은 날·같은 홀의 발표를 한 세션으로 묶고, 가장 이른
시작부터 가장 늦은 종료까지를 그 세션의 시간으로 삼는다. 원본은 이걸 말해 주지 않지만
복도에 서 있는 사람에게 필요한 건 그거다.

## 일정은 이 브라우저에만 있다

`localStorage`는 기기마다 따로다. 노트북에서 담은 일정은 폰에 자동으로 넘어가지
않고, 서버가 없으니 계정으로 맞출 방법도 없다. 그래서 **내 일정 → 링크 복사**가
일정 자체를 주소에 담는다 (`#p=0265,0882,…`). `#` 뒤는 브라우저가 서버로 보내지 않는
부분이라 아무것도 업로드되지 않는다.

링크를 열면 **합친다**. 그 기기에 이미 있던 것은 그대로 두고, 가져온 건수를 알려준 뒤
주소에서 조각을 지운다 — 새로고침했을 때 지나간 일정이 되살아나지 않도록.

## 겹침

같은 시간에 서로 다른 홀의 발표를 둘 담으면 둘 다 갈 수 없다. 양쪽에 표시하고 건수를
문장으로 알려준다. 같은 홀 안에서 겹치는 건 세션이 이어지는 것뿐이라 세지 않는다.
